# Frontend Implementation

Before implementing:

1. Read `.agents/rules/frontend.md`.
2. Inspect the target feature.
3. Find existing project patterns.
4. Verify API contract where integration is involved.
5. Reuse shared abstractions.

Do not:

- redesign without request;
- invent API contracts;
- add dependencies unnecessarily;
- refactor unrelated code;
- introduce new architecture when existing patterns work.

Follow the approved implementation plan.

After implementation, self-review and report manual-test scenarios.
