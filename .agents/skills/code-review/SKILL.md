# Code Review

Review in priority order:

1. Functional correctness
2. Regression risk
3. Backend contract compliance
4. State/query correctness
5. Type safety
6. Existing architecture consistency
7. Error handling
8. Accessibility/responsive UX
9. Maintainability

Identify concrete issues first.

Do not suggest redesign or refactor unless necessary to fix a real issue.

Distinguish:

- blocker;
- should fix;
- optional improvement.
